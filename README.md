# 余音 Yuyin Music

基于 Electron + React + TypeScript 的 Windows 桌面音乐播放器。前台为独立听歌界面，后台浏览器加载 Bilibili 原视频，只输出声音。

Windows x64 安装版为 `release/Yuyin-0.4.9-Setup.exe`（约 109 MiB），可复制给其他电脑安装，无需额外安装 Node.js。先关闭正在运行的余音，再双击安装包，按中文向导选择安装位置；默认安装到当前用户，创建桌面与开始菜单快捷方式，系统“已安装的应用”中提供卸载入口。

便携版为 `release/Yuyin-0.4.9-Windows.exe`，可直接双击运行。开发、便携和安装版本共用 `%APPDATA%/YuyinMusic` 音乐库、设置及浏览会话，安装到其他目录不会清空数据。标准卸载保留数据，再次安装可继续使用；换电脑时数据不会自动同步。当前安装包未做数字签名，Windows 可能显示未知发布者提示。

收藏、歌单、历史、队列和听歌偏好在操作完成时立即写入 `%APPDATA%/YuyinMusic/library.json`，与程序所在目录无关。写入采用临时文件替换，并保留上一份有效记录 `library.json.bak`；主文件损坏时读取备份，两份都无法读取时会提示错误并保护原文件。首次启动新版会自动迁移原浏览器音乐库。网页预览仍使用浏览器本地存储。

歌词来源、两个来源的缓存和校准、静音前音量、睡眠定时以及主窗口大小、位置、最大化状态保存在同目录的 `preferences.json`，立即保存并保留有效备份。旧版浏览器设置自动迁移；歌词校准独立长期保存，不随歌词下载缓存过期或被淘汰。重启后恢复未到期的睡眠定时，已到期的定时自动清除。Bilibili 登录继续使用原来的本机会话。

## 运行

需要 Node.js 22.12 或更新版本。

```sh
npm install
npm run dev
```

生产构建与启动：

```sh
npm run build
npm start
```

生成 Windows 安装版和便携版（输出到 `release/`）：

```sh
npm run dist
```

只生成安装版使用 `npm run dist:installer`；只生成便携版使用 `npm run dist:portable`。安装包采用 NSIS 中文向导，文件名分别为 `Yuyin-版本号-Setup.exe` 和 `Yuyin-版本号-Windows.exe`。

本机系统 npm 运行时异常时，可使用可用的 Node.js 运行 `node scripts/package-with-runtime.cjs --installer --prepackaged`，从已经构建好的 `release/win-unpacked` 生成安装包；此命令不会重新编译源代码。去掉 `--prepackaged` 则重新打包已有的生产构建，去掉 `--installer` 则生成便携版。源代码有修改时须先完成类型检查及生产构建。

如果 npm 提示 Electron 安装脚本未执行，可以运行 `node node_modules/electron/install.js` 安装官方运行时。网络下载失败时，检查本机到 GitHub 的连接。

## 已实现

- 启动时校验 Bilibili 账号，未登录先显示登录引导，完成官方登录后自动进入；已登录的本机会话可直接进入。
- 右上角显示 Bilibili 昵称与头像，鼠标移入、点击或键盘操作可展开账号菜单，进入个人空间、收藏夹和听歌设置，或管理账号及刷新登录状态。
- Bilibili 原站搜索，采用官方综合排序，完整保留返回的视频顺序；搜索只显示结果，点击歌曲才开始播放。
- 独立后台浏览窗口播放原视频；暂停、继续、上一首、下一首、拖动进度、音量及静音。
- 列表循环、随机播放、单曲循环、播放队列管理。
- 新建、重命名、删除歌单，向歌单添加及移除歌曲。
- 收藏、取消收藏；真实开始播放后记录最近 100 首历史。
- 本地自动保存音乐库及偏好；JSON 备份导出和合并恢复。
- 15/30/60/90 分钟睡眠定时、快捷键和系统媒体按键。
- Bilibili 登录/验证窗口、源视频查看窗口；浏览会话保存在本机。
- 播放时默认读取 Bilibili 视频字幕，也可切换 LRCLIB 搜索歌词；底部“词”或侧边栏“正在听 · 歌词”打开歌词页。
- LRC 逐句高亮、自动滚动、点击歌词跳转；纯文本歌词及纯音乐状态。
- 搜索歌词每次提前/延后 0.5 秒，Bilibili 字幕每次提前/延后 0.1 秒，也可重置时间；匹配及偏移按 Bilibili 视频保存在本机。
- 「校准歌词」后，在听到一句开始时点击对应歌词，一次设置时间差；播放位置保持当前进度，校准结果自动保存。
- 歌词页可切换「搜索歌词」与「Bilibili 字幕」，记住来源偏好；两个来源分别保存歌词和时间微调。
- 独立透明置顶桌面歌词，显示当前句与下一句，主窗口最小化后继续跟随；支持微软雅黑、宋体、楷体、幼圆，以及字号和三种颜色，记住字体与窗口位置。

搜索结果由 Bilibili 官方接口按综合排序返回，余音不再按播放量重新排列。原视频可能是 MV、翻唱或合集。推荐区为从真实 Bilibili 搜索获取的初始精选，搜索结果会实时获取。

## 使用与边界

桌面客户端启动后先检查本机 Bilibili 会话。未登录时点击登录引导中的按钮，在 Bilibili 官方窗口完成登录；余音自动检查，也可手动重新检查。网络失败时显示重试入口。账号失效时暂停播放并回到登录引导，桌面歌词暂时隐藏，重新登录后恢复原来的开启偏好、样式和位置。收藏、歌单和设置继续保存在本机。

首次搜索或播放若遇到 Bilibili 验证，点击“打开 Bilibili 登录 / 验证”，在原站完成操作后重新搜索或播放。部分视频受登录、会员、地区、版权或源站删除限制，播放器会显示真实错误。后台播放基于原视频 HTML5 播放器，仍会加载视频数据，并非下载 MP3 或纯音频流；可在源视频窗口设置较低画质减少开销。

播放器在隐藏窗口中播放，但前台界面不会加载 Bilibili 的脚本。关闭主窗口会结束后台播放及整个应用。当前未提供音频下载、离线播放、自行生成 AI 歌词、云端账号同步或手机应用。

## 自动歌词

默认选择「Bilibili 字幕」，手动切换后的来源会记住。也可选择来自 [LRCLIB](https://lrclib.net/) 的搜索歌词；查询与音源播放独立，歌词超时或未匹配不会阻塞音乐。搜索匹配优先考虑视频标题中的歌名、歌手和录音版本，UP 主名称不被直接当成演唱者。MV 片头等固定时间差可以点「校准歌词」，在听到一句开始时点击该句，对齐后自动保存；也可用“− / +”微调。现场、变速或中途剪辑造成的节奏差异，单次校准无法持续对齐，需改选对应版本或视频字幕；合集会谨慎处理，无法确认时显示暂无歌词。

「Bilibili 字幕」读取当前视频首 P 已向你的原站会话提供的字幕，优先中文 AI 字幕，并准确标明 AI 自动字幕或 UP 主字幕。它使用视频本身的时间轴，不按歌名匹配。Bilibili 要求登录时可在登录窗口完成后重新获取；未提供字幕的视频无法由余音要求 Bilibili 为其生成字幕。AI 对歌声可能误识别，字幕内容也可能包含对白，可随时切回搜索歌词。

同步歌词每 100 毫秒读取原音源实际进度。Bilibili 字幕即时更新高亮和居中位置，减少短句出现时的动画延迟；字幕原始时间戳保持不变。普通模式下点击一行会跳到该行时间加已保存的偏移；校准模式下点选当前唱词只调整歌词时间差。正偏移使歌词延后，负偏移使歌词提前；普通文字歌词没有逐句时间，不提供跳转或校准。重新查找得到不同歌词时间轴时，旧校准会重置。

每个来源的本机下载缓存最多保留 50 个视频及约 1.5 MiB：歌词匹配缓存 30 天，未匹配结果缓存 5 分钟。时间校准独立保存，下载缓存过期后重新取得相同歌词时间轴仍会恢复偏移；换成不同歌词时间轴时重新校准。刷新按钮可重新查询；刷新失败时保留已显示歌词。当前音乐库 JSON 导出仅覆盖收藏、歌单、队列、历史和播放偏好；歌词与其他设置文件独立保存并保留有效备份。

## 桌面歌词

点击底部播放器的屏幕图标，或在「设置与音乐库备份 → 桌面歌词」开启。它使用当前选择的歌词来源及时间校准，显示正在唱的一句和下一句；主播放器最小化后仍会更新。没有同步歌词时显示状态提示，文字歌词不会冒充同步歌词。

桌面歌词上方的工具栏会在鼠标移动到窗口时显示，约 2.2 秒无操作后自动隐藏。工具栏可以切换微软雅黑、宋体、楷体、幼圆，调整 24–56 像素字号、月白/薄荷/暖金颜色和 30%–100% 透明度；锁定按钮会禁止窗口移动，但仍可操作工具栏。拖动歌词文字、空白、曲名或工具栏左侧都可移动窗口；设置按钮与下拉菜单正常点击，较长的句子会自动缩小或换行。点击工具栏的关闭按钮只关闭桌面歌词；关闭整个播放器会同时关闭歌词窗口。

开关、锁定、字体、字号、颜色、透明度与位置保存在 `%APPDATA%/YuyinMusic/desktop-lyrics.json`，重启恢复，并保留上一份有效备份。退出时等待已接受的设置操作和最后的拖动位置保存。字体采用本机系统字体，缺少某款字体时使用备用字体。桌面歌词偏好独立于音乐库 JSON 导出。

```sh
npm test

```

`docs/QA.md` 提供实际播放、来源验证和数据保存的验收步骤。

已在真实 Electron 环境验证搜索与手动播放、暂停、精确跳转、恢复、音量、结束通知和历史记录；打包后的客户端启动也已通过。各版本的具体排序和测试范围见 `docs/QA.md`。

## 主要文件

- `electron/main.ts`：窗口、IPC 参数校验与备份对话框。
- `electron/library-store.ts`：固定音乐库文件、同步原子保存与损坏备份恢复。
- `electron/preferences-store.ts` / `electron/desktop-settings-store.ts`：其他设置与桌面歌词样式的固定文件保存、验证和备份。
- `src/local-preferences.ts` / `src/ui-settings.ts` / `src/lyric-calibrations.ts`：旧设置迁移、静音与定时恢复、长期歌词校准。
- `electron/bilibili.ts`：原站搜索与登录窗口。
- `electron/player.ts`：后台网页播放、状态监听和队列结束通知。
- `electron/lyrics.ts`：LRCLIB 查询、超时、缓存及 IPC 数据验证。
- `electron/subtitles.ts`：Bilibili 视频字幕查询、登录状态提示及字幕时间轴转换。
- `src/App.tsx`：页面与听歌交互。
- `src/LyricsView.tsx` / `src/useLyrics.ts`：歌词页面及切歌、刷新、偏移状态。
- `src/lyrics.ts` / `src/lyrics-storage.ts`：匹配、LRC 解析及歌词持久化。
- `src/library.ts`：持久化、歌单、收藏、历史和播放模式。
