## 核心体验

- 搜索：歌名模式只发送完整输入，并按标题连续包含筛选，不追加联想词；视频模式请求 Bilibili 官方综合排序，不筛选或按播放量重排。模式选择重启保留，旧库默认歌名。切模式与重复搜索不会被慢旧请求覆盖；搜索不触发播放、替换队列或打断当前歌曲。加载更多沿原分页顺序追加并去重，歌名过滤空页仍可继续下一页，匹配数不冒用源总数。
- 登录：可主动选择游客进入，右上角能再登录；游客仍可管理本地收藏，个人空间与账号收藏夹要求真实登录。游客与已验证账号切换保留主界面状态，重开程序再次提供登录／跳过。
- 播放：新选歌曲和同曲重播从头开始，启动时历史恢复不夺回进度；暂停继续及手动跳转保留所选位置。播放、暂停、上一首、下一首、音量和进度控制反映后台播放器的实际状态；加载中、暂停、结束和播放错误有不同状态。
- 后台：切换应用页面、隐藏来源窗口或最小化主窗口后，音频继续播放。关闭整个应用后，后台来源窗口与声音一起退出。
- 队列：直接播放、下一首播放、追加播放、移除当前曲目和清空队列行为明确；列表循环、单曲循环与随机播放在结束事件中均生效。
- 收藏与歌单：同一视频不会重复保存；新建、重命名、删除歌单、添加和移除歌曲后重启应用，数据一致。空歌单有可用的空状态。
- 播放历史：由真实播放记录生成；同一首反复播放的处理一致，历史列表有合理上限，支持再次播放。
- 文件持久化：写入失败可见；损坏的本地数据文件不会使应用无法启动；备份/恢复保持 Bilibili 视频 ID、曲目元数据和歌单关联有效。

## 歌词回归

- 双来源：搜索歌词与 Bilibili 字幕可随时切换，音源播放不中断；当前来源有明确状态，AI 自动字幕与 UP 主字幕分别标记。中文字幕优先。
- 登录与可用性：Bilibili 返回需要登录时显示登录按钮及登录后重新获取；没有字幕时提供切回搜索歌词；不得将“读取已有字幕”描述为自动生成字幕。
- 来源隔离：同一视频的两个来源分别保存缓存、时间偏移，来源偏好持久化；切来源的慢旧请求不能写回当前显示。
- 自动获取：点击搜索结果，以及从歌单、收藏、历史再次播放时，自动查询当前视频的歌词；查询过程中音乐和原有页面操作可继续使用。
- 同步歌词：逐句高亮与后台实际播放时间一致；暂停后歌词停止推进，恢复后继续；前后拖动进度、回到开头和跳至结尾后，高亮与滚动位置重新对应当前进度。
- 点击跳转：点击歌词跳至该句时间加用户偏移的位置；目标时间小于 0 时从 0 秒开始，超出视频时由播放器限制在可播放范围内。
- 时间微调：搜索歌词每次 0.5 秒、Bilibili 字幕每次 0.1 秒，提前、延后和重置操作立即生效，正偏移表示歌词延后，范围限制为 ±180 秒；重新播放同一视频或重启后恢复已保存的偏移。
- 点选校准：进入「校准歌词」后听到一句开始时点选该句，只改变歌词偏移，原视频位置不变；普通点击仍跳转。校准中暂停自动跟随滚动以便选句，取消或完成后恢复；缓冲及错误时仍能取消。
- 校准隔离：切歌、切来源、切到其他来源再切回期间，旧校准请求不得更新偏移或显示成功；无文字的间奏不可校准，超过 ±180 秒的校准给出提示且不写入。重新获取不同歌词时间轴时重置旧偏移，同一时间轴保留。
- 歌词解析：支持多时间标签、不同小数精度、LRC 自带的 offset、重复歌词与间奏空行；元数据不显示为歌词，异常时间标签不使页面崩溃。
- 版本匹配：优先按当前视频标题和原搜索词匹配歌名、歌手及录音室/现场版本；同名前缀不同的歌曲和合集不误配为单曲歌词。匹配仍需人工检查，翻唱或片头差异可通过时间微调处理。
- 降级显示：仅有普通歌词时显示可换行的文本，不提供时间跳转；纯音乐、无匹配、网络错误和加载状态有明确提示，均不阻断后台播放。
- 切歌与刷新：快速连续切歌、慢请求晚返回、重复重新获取时，只显示当前视频对应的歌词；刷新失败保留已有歌词并显示错误，重新获取成功后更新文本并保留当前视频的用户偏移。
- 本地缓存：匹配结果保留 30 天，未匹配结果保留 5 分钟；到期后重新获取。缓存按 Bilibili 视频 ID 保存，保留最近最多 50 个视频，并限制总 JSON 大小为 1.5 MiB。
- 缓存容错：损坏条目不影响其他有效缓存；歌词字段过长或类型错误时拒绝保存；存储空间满或权限异常时显示保存提示，当前会话中的歌词和时间微调仍可使用。
- 备份范围：歌词来源、两个来源的缓存和长期校准保存在 `preferences.json`，桌面歌词样式与位置保存在 `desktop-lyrics.json`，均独立于主音乐库；当前音乐库导出/导入不包含这些文件。下载缓存过期不删除校准；换电脑时须另行保留这两个文件，浏览器存储清除不影响已迁移的文件设置。

## 网络与来源页面

- 无网络、搜索超时、搜索无结果、平台限制、视频删除或不可播放时，展示能执行下一步的错误；失败不会留下永久加载状态。
- 要求登录或验证时可以打开 Bilibili 来源窗口；完成后可重试，来源会话在重启后保持。
- 切歌过程中连续点击两首以上歌曲，最终只播放最后一次选择，并且不会出现两路声音。
- Bilibili 视频分 P 或默认自动连播时，应用队列只响应一次当前曲目的完成事件，不会与网站推荐视频同时争抢播放。
- 后台网页尚未创建 video 元素时耐心等待并设置超时；恢复或重试不会创建重复轮询计时器。

## 隔离与构建

- Bilibili 窗口使用 `nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`，且不加载主界面 preload。
- 远程页面不能导航主界面或调用本地文件 IPC；应用 IPC 校验发送者、输入类型和长度。
- 新窗口和外部链接仅允许明确支持的 HTTPS 来源；不开放任意 `shell.openExternal` 或 URL 加载接口。
- 远程会话不默认授予摄像头、麦克风、定位等权限，保持 `webSecurity` 开启。
- 正式构建可在不运行 Vite 的情况下打开本地界面，preload 路径正确，背景窗口与本地资源随应用打包。
- TypeScript 检查、生产构建及针对队列/数据迁移的必要检查通过；实际 Bilibili 搜索与后台出声应独立记录人工验证结果。
